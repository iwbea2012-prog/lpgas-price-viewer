# 器具価格 照会ビューア

LPガスの得意先ごとに違う「ガス機器・器具類」の販売単価を、外出先のスマホから一瞬で引くための、
**読み取り専用**ツール。月1回、基幹システムの販売履歴CSVを取り込んで更新する。

- 中身は AES で暗号化。合言葉を知っている人だけが見られる。
- 公開URL（GitHub Pages）に置いても、合言葉がなければただの暗号文。
- 一度開けば以降はオフラインで動作（データはHTMLに埋め込み済み）。

## ファイル構成

| ファイル | 役割 | 配置 |
|---|---|---|
| `index.html` | スマホ用ビューア（**暗号化済みデータ入り**）。GitHub Pages のトップ。 | リポジトリに置く／毎月差し替え |
| `builder.html` | 履歴CSV → `index.html` を生成するツール。**PCのブラウザで開く。通信しない。** | リポジトリに置いておく（中身に秘密なし） |
| `viewer-template.html` | ビューアの元ソース（データ未取込の雛形）。UIを直すのはここ。 | 開発用 |
| `tools/embed-viewer.mjs` | `viewer-template.html` を `builder.html` に埋め込むビルド手順。 | 開発用 |
| `sample-data.csv` | 動作確認用のダミーデータ（実在の店・価格ではない）。 | 開発用。**本番リポジトリには置かない** |
| `tools/gen-big-dummy.mjs` | 大きめ（デフォルト12万行・約10MB）のダミーCSVを生成し、`builder.html` を実ブラウザで負荷確認するためのツール。実行すると `big-sample-data.csv` を書き出す（`.gitignore` 済みでコミットされない）。 | 開発用 |

## 毎月の更新手順（運用）

1. **基幹システム**から直近3ヶ月ぶんの販売履歴を **CSV** で書き出す
   （列に「伝票日付・得意先・商品・数量・単価」が並ぶ形式。文字コードは Shift-JIS でも UTF-8 でも可）。
2. PC で `builder.html` を開く（GitHub Pages の `.../builder.html` でも、手元のファイルをダブルクリックでも可）。
3. CSV をドラッグ＆ドロップ → **列の対応づけ**を確認（初回だけ。次回からは記憶される）。
4. 「集計してプレビュー」で件数・期間・サンプルを確認。
5. **合言葉**を入力（社内で共有しているもの）→「index.html を生成してダウンロード」。
6. GitHub のリポジトリ画面 → **Add file → Upload files** で、ダウンロードした `index.html` を上書き → Commit。
   - **CSV と builder.html はアップロードしない。**
7. 2〜3分後、スマホのホーム画面アイコンから開くと最新になっている。

## CSVが大きい／読み込みが重いとき

`builder.html` はCSVを逐次読み（全行を配列に展開せず、直近3件だけ保持しながら集計）ので、
数十万行・十MB規模でも数百ms〜数秒でタブが固まらずに処理できる（`tools/gen-big-dummy.mjs` で
生成した12万行・約10MBのダミーCSVで確認済み）。

それでも重い・時間がかかる場合は、**基幹システムのエクスポート自体を絞る**のが最も効果的。
このビューアが実際に使うのは「直近数ヶ月 × 器具・機器カテゴリ × 9列だけ」なので、以下を確認する：

1. **期間** を直近4ヶ月程度に絞れないか（ビューア側の「直近何ヶ月」設定と合わせる）。
2. **商品カテゴリ** で「器具・機器」だけに絞れないか（ガス本体・検針・配送関連の伝票は不要）。
3. **列** を絞れないか（伝票日付・得意先コード／名・商品コード・商品名・メーカー・単位・数量・単価の
   9列があれば十分。それ以外の列が混ざっていても `builder.html` の「列の対応づけ」で無視できるが、
   出力時点で削れるなら列数もファイルサイズに効く）。

**CSVは実データも含めて、このチャット（AIアシスタント）には貼らない・添付しないこと。**
`builder.html` がブラウザの中だけで処理する設計なので、AIに渡す必要は一切ない。

## 初回セットアップ

### GitHub Pages
1. GitHub で新規リポジトリを作成（例 `lpgas-price-viewer`）。
2. このフォルダの `index.html` `builder.html` をアップロード
   （`viewer-template.html` `tools/` も入れてよい。`sample-data.csv` は入れない）。
3. Settings → Pages → Branch: `main` / フォルダ `/ (root)` → Save。
4. 数分後 `https://<ユーザー名>.github.io/<リポジトリ名>/` で表示される。

### スマホ（各自）
1. 上のURLを Safari / Chrome で開く。
2. 共有メニュー →「ホーム画面に追加」。
3. アイコンから開き、**合言葉を1回入力**（「この端末におぼえておく」ON で次回から不要）。

### UIを修正したとき（開発者向け）
```
node tools/embed-viewer.mjs      # viewer-template.html を builder.html に再埋め込み
```

## 画面

- **ホーム**：データ基準日、最近見た単価、得意先一覧、「器具から探す（横断）」ボタン。
- **得意先を選ぶ**：その店が直近3ヶ月に買った器具を、器具名・品番で検索 → 直近単価。
  行をタップで、メーカー・単位・数量・これまでの単価（過去2〜3回）を表示。
- **器具から探す（横断）**：器具名で全得意先を検索。扱いのある店と直近単価を安い順で一覧。

## セキュリティの注意

- **合言葉は長めに**（日本語や英単語を4語以上、12文字以上を推奨）。公開URLに暗号文が載るため、
  短い合言葉は総当たりに弱い。
- 担当者が入れ替わったら**合言葉を変更**し、次回ビルドから新しい合言葉にして再共有する。
  （古い端末に残ったキーは、新しいデータを復号できず自動で無効になる。）
- **CSV（平文の実データ）は絶対にコミット／アップロードしない。** `.gitignore` で `*.csv` を除外済み。
- `builder.html` は CSV をローカル処理するだけで、外部送信は一切しない。
